# 🍃 CookToSave — Receitas Inteligentes
Uma plataforma de receitas desenvolvida para ajudar pessoas a encontrarem opções de pratos utilizando ingredientes que já possuem em casa, incentivando a criatividade na cozinha e evitando o desperdício de alimentos.

## 📌 Sobre o projeto
O CookToSave é uma aplicação web desenvolvida como projeto escolar, com o objetivo de facilitar a busca por receitas de acordo com os ingredientes disponíveis na casa do usuário.
A plataforma permite criar uma conta, selecionar ingredientes, pesquisar receitas e salvar pratos favoritos.

## ✨ Funcionalidades
- Cadastro e login de usuários.
- Pesquisa de receitas por ingredientes.
- Seleção de ingredientes disponíveis.
- Sistema de receitas favoritas.
- Experiência personalizada para cada usuário.
- Interface responsiva.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Spoonacular API
